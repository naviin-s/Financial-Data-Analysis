# 📊 Financial Sales Analysis | Power BI

## 📌 Project Overview

This project focuses on analyzing financial sales data using **Microsoft Power BI** to evaluate business performance and identify important sales trends.

The project involved preparing and transforming the dataset using **Power Query**, developing business KPIs using **DAX**, and creating **four interactive dashboards** to analyze sales performance across products, categories, regions, sales representatives, and customers.

The project demonstrates an end-to-end **Business Intelligence and Data Analytics workflow**, from data preparation to visualization and insight generation.

---

## 🎯 Project Objectives

- Analyze overall financial sales performance.
- Identify sales trends across different dimensions.
- Evaluate product and category performance.
- Compare regional and sales representative performance.
- Understand customer purchasing behavior.
- Develop interactive dashboards to support data-driven decisions.

## 🔢 DAX Measures

Some of the key measures developed in the project include:

### Total Sales

```DAX
Total Sales = SUM(Sales[Sales_Amount])
```

### Total Quantity Sold

```DAX
Total Quantity Sold = SUM(Sales[Quantity_Sold])
```

### Total Transactions

```DAX
Total Transactions = COUNTROWS(Sales)
```

### Average Sales

```DAX
Average Sales = AVERAGE(Sales[Sales_Amount])
```

> Column and table names may need to be adjusted according to the actual Power BI data model.
